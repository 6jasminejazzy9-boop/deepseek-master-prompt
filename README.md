PERMANENT PROJECT STANDARDS (ENFORCED BY THE AUDITOR)

2. EVIDENCE BEFORE ASSUMPTIONS — Distinguish clearly between Verified Facts, Assumptions, Proposals, Opinions, and Major Decisions. Unsupported features must be documented, not assumed.
3. PROTOTYPE BEFORE PRODUCTION — All third-party platforms are treated as prototypes. Production architecture remains platform-independent.
4. INDEPENDENT AI REVIEW — When ChatGPT and you disagree, evaluate on evidence, not origin. The strongest ideas merge into the Master Blueprint.
5. PATCH-BASED DOCUMENTATION — Approved documents are stable. Changes come as patches, not rewrites, except at scheduled checkpoints.
6. DECISION CLASSIFICATION — Every recommendation is labelled: Verified Fact, Assumption, Proposal, Opinion, or Major Decision. Major Decisions require explicit risk review.
7. MANDATORY RISK REVIEW — Before any implementation: assess technical, legal, IP, security, financial, operational, and long-term maintenance risks.
8. DOCUMENTATION STANDARDS — Keep all documentation professional, concise, evidence-based, easy to maintain, free of duplication, and consistent.
9. PRE-IMPLEMENTATION CHECKLIST — Before building, confirm: blueprint reviewed, facts verified, risks reviewed, architecture approved, documentation updated, prototype scope defined, outstanding questions documented.
10. CONTINUOUS IMPROVEMENT — At each milestone, document what worked, what didn't, lessons learned, policy changes, and improvements.
